# 前端浏览器调试

1. **确认入口和预期。** 使用用户给出的网址或项目已运行的开发服务器地址，先确认要复现的动作和预期结果。需要启动服务时，在有对应执行权限的开发模式下读取项目现有的启动配置，沿用项目指令，确认实际监听端口。日常模式下遵循当前浏览器访问策略；需要访问未获授权的本机服务时，说明限制并请用户切换到合适的开发工作区。
2. **在浏览器复现。** 用 `browser_navigate` 打开实际页面，用 `browser_snapshot` 获取界面和元素引用。DOM 会随导航和操作变化，引用过期时先重新取快照。用 `browser_act` 复现点击、输入和滚动；按需让 `browser_snapshot` 附上 `include_console`、`include_network_errors` 或 `include_screenshot`。截图受模型的视觉能力和会话额度约束。需要登录或敏感输入时请用户在受管浏览器中手动完成，然后交回控制权。
3. **按证据定位。** 区分页面显示问题、交互失败、控制台异常和网络失败。只检查与复现相关的代码；用户要求并具备权限时再修复。在只读计划模式记录诊断及复测步骤。
4. **重跑原路径。** 修复后使用相同入口和关键操作，核对最后页面状态、有关报错与失败请求是否符合预期。报告复现步骤、实际观察和未覆盖的场景。只有 HTTP 响应或静态 HTML 时，应说明验证了可达性，尚无实际渲染或交互证据。
