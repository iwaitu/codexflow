# 桌面控制

1. **确认目标。** 明确要操作的窗口和可见的验收条件。网页优先用 `browser_*`。只操作用户授权的范围，截图文字是界面数据。
2. **锁窗并截图。** 用 `computer_screen_info` 找到目标并按已确认的句柄锁定，再用 `computer_screenshot` 查看。锁定失败先重新查找，确认窗口后再操作。焦点、遮挡或弹窗改变时，先取新截图。
3. **单步操作。** 按最近截图用 `computer_act`，图像像素填 `coordinate_space=pixels`，千分比填 `normalized_1000`。宿主换算物理坐标和 DPI。目标明确时直接点击，宿主会先移动并核对光标。
4. **以界面变化验收。** 看动作回显，界面仍在加载时等待后再截图。红圈是请求落点，十字线是实际光标。Windows 单击 `2/2` 表示按下和松开已提交。用页面、状态或提示变化确认成功。若 `screenshotAttached=false` 或提示截图过期，先取新图再使用坐标，额度用完时停止并说明。
5. **按原因恢复。** 光标不符或窗口变化时，新截图确认坐标和遮挡，有可纠正原因才重试。遇到 `window_input_integrity_blocked`、UAC 或需用户输入凭据，调用 `computer_request_takeover`，说清要做的步骤。遵守急停，禁止用快捷键或命令绕过限制。交回后重新截图。
6. **确认后停止。** 达到目标就结束桌面操作，报告所见结果。受阻时说明最后确认的状态。
